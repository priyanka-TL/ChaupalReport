# CLAUDE.md — Chaupal Report Generation Pipeline

## Project Overview

This project processes raw Shiksha Chaupal discussion data (CSV) and produces:
- A narrative Word report: `Final_Shiksha_Report.docx`
- A validation CSV report: `Chaupal_Validation_Report.csv`

Each row in the input represents one Chaupal (community discussion) session. A single row can contain **multiple challenges and solutions**, pipe-separated (`|`). Each individual challenge/solution is independently mapped to exactly **one theme**.

---

## Pipeline — Run in Order

```bash
python3 0_data_cleaner.py
python3 1_data_prep.py
python3 2_ai_tagger.py
python3 3_final_processor.py
python3 4_validation_report.py
```

| Script | Purpose | Key Output |
|---|---|---|
| `0_data_cleaner.py` | Cleans participant counts (JSON/plain/reconcile) | `cleaned_data.csv` |
| `1_data_prep.py` | Explodes `\|`-separated challenges/solutions into individual rows; builds unique text pools | `exploded_challenges.csv`, `exploded_solutions.csv`, `unique_challenges.csv`, `unique_solutions.csv` |
| `2_ai_tagger.py` | Batch-sends unique texts to LLM; assigns one theme + `Merged_Concept` per item | `challenge_mapping.csv`, `solution_mapping.csv` |
| `3_final_processor.py` | Merges mappings, classifies environments/agency, runs optional refinement, computes metrics, generates Word report | `Final_Shiksha_Report.docx` |
| `4_validation_report.py` | Aggregates mapped challenges/solutions per Chaupal, adds participant % | `Chaupal_Validation_Report.csv` |

## Key Data Design

### Multi-value fields
- `Challenges` and `Solutions` columns in the raw CSV use `|` as a delimiter.  
- `1_data_prep.py` **explodes** these into one-row-per-item (many-to-one with the source Chaupal `id`).
- Each exploded item gets mapped to exactly **one theme** independently.

### Theme Taxonomy (10 themes, exactly)

| # | Theme | Notes |
|---|---|---|
| 1 | Poverty and Economic Barriers | Financial hardship, child labour |
| 2 | Legal Document-linked Barriers | Missing Aadhaar, birth certificates |
| 3 | Child Marriage Issue | Early marriage preventing education |
| 4 | Distance and Accessibility Issues | School far, bad roads, weather |
| 5 | Parental Attitudes & Socio-Cultural | Mindsets against girls, dowry, domestic roles |
| 6 | School Infrastructure & Facility | Toilets, water, mid-day meals, books, govt schemes |
| 7 | Teacher Capacity & Quality | Shortage of teachers, irregular attendance |
| 8 | Safety Issues | Harassment, unsafe routes, stray dogs |
| 9 | Substance Abuse & Addiction | Alcohol, drugs, gambling, mobile addiction |
| 10 | Other Factors | General awareness, migration — target < 10% |

Rules:
- Each item gets **exactly one** theme — never combined with `+` or `and`.
- Pick the **most dominant** theme when multiple could apply.
- `Other Factors` is a fallback; keep below 10%.

### Merged_Concept
Each challenge/solution also receives a canonical `Merged_Concept` — a short phrase that semantically deduplicates similar texts across the dataset. Used for grouping in thematic analysis.

## Classification Layers (applied in `3_final_processor.py`)

**Challenge Environment:**
- `School` — happens inside or due to the school
- `Home` — family/household context
- `Community` — village/social/systemic context

**Solution Agency:**
- `Individual-led` — action by a parent/student
- `Community-led` — collective community action
- `Institutional` — school/government/NGO led

## AI / LLM Configuration

Set via environment variables or `.env` file:

```
LLM_PROVIDER=claude   # or gemini
```

**If claude (AWS Bedrock):**
```
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_REGION=ap-south-1
CLAUDE_MODEL_ID=global.anthropic.claude-sonnet-4-5-20250929-v1:0
CLAUDE_MODEL_VERSION=bedrock-2023-05-31
```

**If gemini:**
```
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.0-flash
```

**Tuning:**
```
LLM_MAX_RETRIES=5
LLM_RETRY_BASE_SECONDS=2
LLM_RETRY_MAX_SECONDS=45
TAGGER_BATCH_SIZE=150
TAGGER_MAX_TOKENS=12000
```

## Intermediate Checkpoints

- `refine_checkpoint_challenge.json` — saves LLM refinement progress for challenges (resume-safe)
- `refine_checkpoint_solution.json` — same for solutions
- `tagger_progress_challenge.json` / `tagger_progress_solution.json` — batch progress for `2_ai_tagger.py`

Delete checkpoint files to force a full re-run of affected stages.

## Important Conventions

- Always run scripts in order (0→1→2→3→4); each script depends on the previous output.
- Do not manually edit `challenge_mapping.csv` or `solution_mapping.csv` — they are LLM-generated.
- Input CSV columns expected: `id`, `Title`, `User name`, `User Location`, `District`, `Participant Count`, `Men`, `Women`, `Children`, `Date of Discussion`, `Organization`, `Challenges`, `Solutions`, `Author`, `Language`, `Report Created At`, `Transcript Link`, `Image Urls`, `PDF Urls`, `PRI Member Information`, `School Representative Information`.
- The `Challenges` and `Solutions` cells may contain 1–N items separated by ` | `.
